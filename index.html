Criterio 1 Sistema de EDOs

Formulación e Interpretación del Modelo Matemático

Aplicando la Segunda Ley de Newton para sistemas de masa variable ($F_{\text{ext}} = \frac{dp}{dt} - v_{\text{escape}}\frac{dm}{dt}$) sobre el eje vertical $y$:

$$\begin{cases} \dfrac{dy}{dt} = v(t), & y(0) = 0 \\[6pt] \dfrac{dv}{dt} = \dfrac{T(t) - F_d(v)}{m(t)} - g, & v(0) = 0 \end{cases}$$
  • • Masa variable $m(t)$: $m(t) = m_0 - \dot{m}t$ para $0 \le t \le t_b$, y $m(t) = m_s$ constante para $t > t_b$.
  • • Empuje $T(t)$: $T = \dot{m}\,v_e$ durante la combustión ($t < t_b = m_p/\dot{m}$) y $T = 0$ tras agotar el propelente.
  • • Gravedad y Arrastre: $-g$ frena el ascenso constantemente; $F_d = \frac{1}{2}\rho C_d A v|v|$ modela la resistencia aerodinámica (opcional).
Hipótesis físicas: Vuelo vertical 1D, campo gravitatorio $g$ constante, flujo másico $\dot{m}$ y velocidad de escape $v_e$ constantes durante el quemado.
Criterio 2 Orden 1 • O(h)

Implementación del Método de Euler

Discretizando el tiempo en $t_n = n \cdot h$, Euler explícito actualiza posición y velocidad usando exclusivamente la derivada al inicio del intervalo:

$$y_{n+1} = y_n + h \cdot v_n, \qquad v_{n+1} = v_n + h \cdot a(t_n, y_n, v_n)$$ 
function stepEuler(t, y, v, h, p) {
  const k1 = derivatives(t, y, v, p);
  const yNext = y + h * k1.dy; // v_n
  const vNext = v + h * k1.dv; // a_n
  return { y: yNext, v: vNext };
}

Criterio 3 Tsiolkovsky + Balística

Solución Analítica de Velocidad y Altura

Para el caso ideal ($F_d = 0$), integrando $\frac{dv}{dt} = \frac{\dot{m}v_e}{m_0 - \dot{m}t} - g$ e integrando $v(t)$ por partes obtenemos:

Fase 1 ($0 \le t \le t_b$):
$$v(t) = v_e \ln\!\left(\frac{m_0}{m_0 - \dot{m}t}\right) - g t$$
$$y(t) = v_e\!\left[t + \frac{m(t)}{\dot{m}}\ln\!\left(\frac{m(t)}{m_0}\right)\right] - \frac{1}{2}g t^2$$
Fase 2 ($t > t_b$, caída libre):
$$v(t) = v_b - g(t - t_b), \quad y(t) = y_b + v_b(t - t_b) - \frac{1}{2}g(t - t_b)^2$$

Criterio 6

Interpretación Física, Comparación de Orden y Conclusiones

Diagnóstico Automático de Simulación

Esquemas Comparados ($\mathbf{u} = [y, v]^T$)

Euler (Orden 1): $\mathbf{u}_{n+1} = \mathbf{u}_n + h\,\mathbf{f}(t_n, \mathbf{u}_n)$. Error global $O(h)$.
Heun / Predictor-Corrector (Orden 2): Promedia pendiente inicial y final: $$\mathbf{k}_1 = \mathbf{f}(t_n, \mathbf{u}_n), \quad \mathbf{k}_2 = \mathbf{f}(t_n + h, \mathbf{u}_n + h\mathbf{k}_1), \quad \mathbf{u}_{n+1} = \mathbf{u}_n + \frac{h}{2}(\mathbf{k}_1 + \mathbf{k}_2)$$
Runge-Kutta 4to Orden (RK4): Promedio ponderado en 4 puntos: $$\mathbf{u}_{n+1} = \mathbf{u}_n + \frac{h}{6}(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4)$$

Conclusión Numérica: ¿Por qué RK4 es superior para el mismo paso $h$?

Al disminuir la masa $m(t) = m_0 - \dot{m}t$, la aceleración $a(t) = \frac{T}{m(t)} - g$ crece de forma no lineal (curva convexa). Euler toma únicamente la aceleración inicial de cada paso (la menor del intervalo), subestimando sistemáticamente velocidad y apogeo. RK4 cancela términos de error hasta cuarto orden en la serie de Taylor ($O(h^4)$), reproduciendo la trayectoria exacta incluso con pasos grandes.
